AI-Based Generation and Screening of Antimicrobial Peptides Using Deep Learning

Chirag · Hurshvardhan Rao · Aniket Mishra

1. Abstract

PeptideLab implements an end-to-end computational workflow for peptide generation, activity classification, toxicity classification and candidate ranking. An LSTM variational autoencoder learns from GRAMPA sequences. Independent compact CNN predictors and random-forest baselines learn from published UniDL4BioPep labels. A local Streamlit interface provides reproducible sampling, user-input screening, evaluation views and CSV export. All results below are computed from saved evaluation artifacts, not copied from research papers.

2. Problem and scope

The objective is to reduce a large sequence search space to a computational shortlist. The general predictors estimate antimicrobial-class membership and the benchmark toxicity label. A separate model for each evaluated organism classifies MIC at a 10 micromolar cutoff. The toxicity label covers the supplied benchmark. Candidate predictions require future experimental investigation.

3. Data and preprocessing

GRAMPA contains 51,345 experimental records and the supplied cleaned file contains 6,760 unique sequences. The final VAE uses 6,510 canonical sequences of length 5–60: 5208 training, 651 validation and 651 test sequences. Classifiers use canonical sequences of length 5–200. Published classifier test splits are retained. Conflicting-label sequences and exact duplicates are removed; any exact train/test overlap is removed from training. Twenty percent of the remaining training set is reserved for validation. Scaling is fitted only on training data.

4. Architecture

Generator: embedding dimension 32; LSTM hidden dimension 96; latent dimension 24. The encoder predicts mean and log variance. Reparameterization samples a latent vector; the decoder receives this vector at every step and through its initial state. Training uses masked reconstruction cross-entropy, KL warmup to weight 0.02, word dropout 0.2, gradient clipping and validation-based checkpoint selection.

Predictors: each task has a separate model. A 24-dimensional residue embedding feeds 32 convolution filters at each kernel width 3, 5 and 7. Masked global max pooling produces 96 features, concatenated with 25 standardized sequence descriptors. A 48-unit hidden layer and dropout feed a binary output. Random forests with 240 trees provide baselines. Validation ROC-AUC selects the best CNN checkpoint and one of CNN, forest or their equal-weight average.

Ranking: 100 × activity_score × (1 − toxicity_score). This is a transparent prioritization rule, not a probability of success. Sampling filters reject truncation, out-of-range length, very low complexity, exact known sequences and duplicates.

In a fixed unfiltered sample of 500 outputs, 500 were distinct; exact novelty against GRAMPA was 100.0%; natural END rate was 100.0%. Teacher-forced test token accuracy was 49.0%, with cross-entropy 1.670. These reconstruction metrics supply the true previous tokens and are not free-running reconstruction accuracy.

Alphabet and minimum-length validity are enforced by decoding. Uniqueness and exact novelty do not demonstrate antimicrobial function or low toxicity. The generator is a statistical proposal mechanism, and quality must not be inferred solely from a large number of unique strings.

9. Limitations and future work

There is no laboratory validation. Model scores are not calibrated probabilities. The classifier evaluation removes exact overlap but does not cluster by sequence similarity, so homologous sequences can cross splits. Activity positives and negatives have different sequence-length distributions, creating an exploitable benchmark bias. Toxicity classes are dataset-specific. Novelty checks exact matches against supplied sequence pools only. The VAE does not guarantee biological function. Further work should include similarity-clustered evaluation, score calibration, external datasets, MIC/species-specific prediction and experimental investigation.

The default baseline uses compact learned residue embeddings. A separate frozen ESM-2 plus CNN implementation and measured comparison are included in the final alignment addendum. It is inspired by the charter's baseline studies and uses their publicly shared benchmark data, but does not claim to reproduce their architectures or published results.

## Architecture and learning workflow

GRAMPA raw records -> canonical unique sequences -> train/validation/test split -> LSTM encoder -> mean/log-variance -> sampled latent vector -> LSTM decoder -> sequence filters -> two independent predictors -> property-screen flags -> ranking -> dashboard and complete CSV.

The compact activity predictor is the validation-selected average of a sequence CNN and random forest. Toxicity uses its independently selected CNN. Each CNN learns residue embeddings and combines sequence features with 25 descriptors. The alternative ESM-2 route freezes a pretrained six-layer, 8M-parameter protein transformer, averages non-special residue embeddings to 320 values, applies a training-only StandardScaler and a separate Conv1D classifier per task. That convolution operates along pooled embedding features, not amino-acid positions; this is an explicit architectural adaptation, not exact UniDL4BioPep reproduction. No task labels update the backbone. Cached embeddings do not fit a model on held-out labels.

Both tasks' validation AUC favors the compact models, so the compact engine remains the default. ESM-2 is fully implemented, locally stored and selectable. Larger pretrained models are not assumed to outperform a measured baseline. Model selection and cutoff selection use validation data; the new ESM comparison is a follow-up using already inspected benchmark test data, not fresh external validation.

## Property screen versus class prediction

Class predictions and reported benchmark accuracy use 0.5. The additional property screen uses validation-selected thresholds: compact activity >= 0.49, toxicity < 0.08; ESM activity >= 0.85, toxicity < 0.14. Activity maximizes validation F1 over the prespecified 0.01..0.99 grid; toxicity takes the highest cutoff reaching at least 95% validation recall for toxic examples. These follow-up rules do not guarantee equivalent recall on new data. Exact validation-file hashes, rules and scores are retained in Results/final/alignment/property_thresholds.json.

Product ranking is 100*A*(1-T). The document equation is also available: S=w*A-(1-w)*T. Displayed priority is 100*(S+1-w), preserving order while mapping the possible range to 0..100. Weights are user preferences chosen before a run, not fitted biological utility. Exports preserve the actual engine, rule, weight, raw weighted score, cutoffs and flags. History preserves earlier results when sidebar settings change.

## Scientific boundaries to explain honestly

The supplied Statistical_Learning.pdf is a literature review/proposed framework, not an additional course grading rubric. Referenced models are background, not a requirement to implement every paper. Binary activity and dataset-specific toxicity are implemented. Species-specific MIC regression, assay-specific hemolysis, laboratory validation, exact reproduction of all cited papers and new discoveries are not claimed.

Exact duplicates are separated within each task, but normalized edit similarity >=0.8 occurs for 943/8877 activity test sequences, 118/580 toxicity sequences and 421/651 VAE sequences versus their training sets. This is not BLAST identity or evolutionary homology. The final project measures the overlap rather than falsely claiming a clustered split. Activity has strong length bias; the short-peptide test subset has only eight negatives and balanced accuracy 0.625. Benchmark accuracy must not be generalized to all novel peptides.
